# RCCM 過去問ノート

RCCM試験 4-1 共通問題（平成20〜30年度・220問）と 4-2 造園（155問）の過去問アプリです。
ブラウザで動き、一度開けばオフラインでも使えます。成績とお気に入りは端末のブラウザ内に保存されます。

## GitHub Pages で公開する手順

1. GitHub で新しいリポジトリを作成します（例：`rccm-quiz`）。Public にします。
2. 「Add file」→「Upload files」で、このフォルダのファイル（フォルダなし・全12個）をまとめてドラッグしてアップロードします。
   - `.nojekyll` は隠しファイルです。表示されない場合はなくても動きます。
3. 「Settings」→「Pages」→ Source を「Deploy from a branch」、Branch を `main`／`/(root)` にして Save します。
4. 数分後、`https://<ユーザー名>.github.io/rccm-quiz/` で開けます。
5. スマホではブラウザの「ホーム画面に追加」でアプリのように使えます。
   一度開いて画面下に「オフラインで使える状態です」と出れば、以後は通信なしで動きます。

## 表示の意味

| バッジ | 意味 |
|---|---|
| 解答なし | 原資料に解答がない問題。正誤判定しません。 |
| 解答なし（推定あり） | 原資料に解答がない問題。採点せず、参考として推定解答と根拠を表示します。 |
| 解答に疑義 | 原資料の解答が誤りと考えられる、または曖昧な問題。理由を表示します。 |
| 複数正解 | 不適切設問として複数の選択肢が正解扱いの問題（H25 問12）。 |

## 更新するとき

`data.js` や `images-*.js` を差し替えたら、`sw.js` 冒頭の `VERSION` の文字列を変えてください。
変えないと、端末に保存された古いデータが表示され続けます。

## ファイル構成

- `index.html` … アプリ本体
- `data.js` … 問題データ（正解・解説・分野・注記）
- `images-1.js` … 4-1 平成20〜25年度の問題画像
- `images-2.js` … 4-1 平成26〜30年度の問題画像
- `images-3.js` … 4-2 造園 問題1〜78の画像
- `images-4.js` … 4-2 造園 問題79〜155の画像（解説用の図表を含む）
- `sw.js` … オフライン用のキャッシュ処理
- `manifest.json`, `icon-192.png`, `icon-512.png` … ホーム画面追加用
